# ORCHESTRATION

## Goal
Ship a static-first, zero-login meme toy that survives social spikes and stays legally/safety clean.

## Build sequence
1. Scaffold baseline with StackForge `next-app`
2. Replace placeholder files with domain-specific UX and deterministic scoring core
3. Add result rendering, explainers, robots/sitemap, tests, smoke scripts, and validation
4. Verify locally with build/test/check/smoke flows
5. Publish repo, set metadata, attempt branch protection

## Constraints
- No external runtime dependency for core scoring flow
- No copyrighted music/video/likeness assets
- No accounts, uploads, or fake live counters
- Result pages should be shareable but `noindex`
